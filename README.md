One line, 160 characters at most: the excuse an AI agent hands its human after missing a deadline. The program writes that line to `/output/entry.txt` and nothing else.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
